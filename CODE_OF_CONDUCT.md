# Code of Conduct

## Short version

Be kind. No harassment, hate speech, or personal attacks — in issues, PRs,
discussions, or DMs about this project. Disagree with ideas, not people.

## Longer version

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
v2.1. Maintainers may warn, then temporarily or permanently ban contributors
who harass others or derail the project.

## Enforcement

Report problems to **ekhore111@gmail.com**. All reports stay confidential.
